# VRIO 对话示范

## 示例一：完整四门引导（质量资源场景）

**用户**：评估一下我们公司的质量相关资源竞争力。

**Agent**：好，我们先列资源项——你可以给粗略清单。质量领域常见的比如：IATF 16949 体系、CNAS 检测资质、核心工艺专利、十年失效数据库、质量文化。你看哪些算你们的？

**用户**：我们有 IATF 16949、CNAS 资质，还有个十年退件数据库。

**Agent**：三项。逐个过四问。先看【IATF 16949 体系】——有价值吗？比如能不能帮你进整车厂供应链、过客户审厂？

**用户**：能，没这个根本进不了。

**Agent**：V=是。稀有吗？同行有多少家也有？

**用户**：做零部件的基本都有吧。

**Agent**：那 R=否（行业普遍）。这两问下来，V是R否 → 至少是个竞争均势。继续——难模仿吗？

**用户**：这个好拿，不算难模仿。

**Agent**：I=否。那这项是"竞争均势"（有价值但不稀有不难模仿）。我们记一下。下一项【CNAS 检测资质】——有价值吗？

**用户**：有价值，客户要求我们自己出检测报告。

**Agent**：V=是。稀有吗？你们地区能做车规 CNAS 检测的实验室多吗？

**用户**：不多，就两三家。

**Agent**：R=是。难模仿吗？CNAS 评审+设备投入+人员，新进入者要一两年？

**用户**：对，门槛高。

**Agent**：I=是。有组织吗？你们检测数据真用在改进吗，还是只出报告？

**用户**：质量部每周拉数据开评审会，算有组织。

**Agent**：O=是。四项全"是" → **持续竞争优势**。继续第三项十年数据库……

> 要点：每问 Agent 给维度与示例，答案由用户判，优势类型按标准逻辑推导。

## 示例二：守住边界 + 跳过

**用户**：十年数据库那项你帮我判四问吧。

**Agent**：不能代判——四问得基于你们真实情况。我帮你回顾：它有没有价值（比如支撑故障预测）？稀有不（同行有类似积累吗）？难模仿不（历史独特+因果模糊通常算难）？有组织用吗（数据进不进分析闭环）？这几个你来判断。

**用户**：这块先跳过，晚点补。

**Agent**：可以。该项标注「供参考·待确认」，报告里优势类型留空、单列说明。我们先进下一项或收尾。

> 要点：拒绝代判，给框架不给结论；跳过标「待确认」并明示影响。
