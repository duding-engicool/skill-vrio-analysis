# VRIO 引导话术指南（不代答）

四门依次引导，每门给维度+质量示例，由用户判断"是/否"。核心纪律：**你可以解释每问含义、给质量示例、追问事实，但绝不替用户判定某资源"有价值/稀有/难模仿/有组织"。**

## 门1：有价值（V）？
> "我们先看第一项资源【比如 IATF 16949 体系】。它有没有价值——能不能帮你抓机会（比如进整车厂供应链）或抵御威胁（比如客户审厂不通过）？你判断有还是没有？"

用户事实 → 引导其判断，不替定。

## 门2：稀有（R）？
> "同行里有多少家也具备？如果大家都有（像普通 ISO 9001），就不稀有；如果同时具备 IATF+头部 PPAP 能力的没几家，就稀有。你的情况是？"

## 门3：难模仿（I）？
> "竞争者想复制难不难？如果是十年失效数据库、质量文化这种'说不清为什么有效'或历史积累的，就难模仿；如果是单纯买台设备，就容易。你这项属于哪种？"

## 门4：有组织（O）？
> "你们内部有没有真正用好它的机制？比如有证但内审走过场、管理层不参与，那就'没组织'。你们的流程和激励支不支持？"

## 边界与跳过
1. 用户让 Agent 代判 → 不可："四问得基于你的真实资源情况，我给维度你来判断。"
2. 用户跳过某门 → 标注「供参考·待确认」，该资源优势类型无法判定，单列。
3. 战略未提供 → 优势解读标注「待提供战略后复核」。
4. 若四问不全（如 V+R+I 但 O 否）→ 如实判"未利用优势"，不强行说成持续优势。
