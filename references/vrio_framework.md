# VRIO 四问评估维度详解

## 1. 有价值（Value）？
资源/能力是否帮助企业：
- 抓住外部机会，或
- 抵御外部威胁，或
- 提升效率/效用创造顾客价值

质量示例：IATF 16949 体系能否帮零部件企业进入整车厂供应链（抓住机会）→ 有价值。

## 2. 稀有（Rarity）？
是否**少数**竞争者同时拥有？
- 行业普遍具备 → 不稀罕
- 仅头部几家有 → 稀有

质量示例：普通 ISO 9001 已普及 → 不稀有；但同时具备 IATF 16949 + 头部客户PPAP能力 → 稀有。

## 3. 难模仿（Imitability）？
竞争者难以复制的原因（任一即可）：
- **因果模糊**：竞争对手看不出成功与资源的因果关系
- **社会复杂**：源于人际/文化/信任（如质量文化、跨域协作）
- **历史独特**：特定路径积累（如十年失效数据库）
- **专利/法律**：受保护

质量示例：质量数据库（十年退件记录）因果模糊+历史独特 → 难模仿；单纯设备 → 易买 → 易模仿。

## 4. 有组织（Organization）？
企业是否具备利用该资源的：
- 正式机制（流程/激励/KPI）
- 组织结构（权责清晰）
- 文化支撑

质量示例：有 IATF 证书但内审走过场、管理层不参与 → 无组织 → 未利用优势。

## 竞争优势映射

|---|---|---|---|------|
| 否 | — | — | — | 劣势 |

| 是 | 是 | 是 | 是 | 持续竞争优势 |
